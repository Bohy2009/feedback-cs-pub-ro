# Data Processing Scripts

Helper scripts for processing and summarizing course evaluation data.

## Scripts

- **`all-extract`** – Generates summary CSV files from processed evaluation data for the full dataset, CTI, and IS.
- **`extract_average`** – Extracts the `"Mediu"` (average) row from each processed CSV.
- **`num_courses_per_group`** – Counts evaluation JSON files by program, study level, and semester, outputting CSV statistics.

Each script expects a single directory path as its input.
